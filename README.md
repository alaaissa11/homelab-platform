# Homelab Platform

Plateforme Kubernetes complète sur WSL2, avec :

- **OpenTofu** : Infrastructure as Code
- **Ansible** : Configuration management
- **K3s** : Cluster Kubernetes
- **ArgoCD** : GitOps
- **Cilium** : Réseau
- **Longhorn** : Stockage
- **Cert-Manager** : HTTPS
- **Sealed Secrets** : Secrets
- **Prometheus + Grafana** : Monitoring
- **Loki** : Logs

## Structure

- `tofu/` : Infrastructure as Code
- `ansible/` : Configuration management
- `argocd/` : GitOps
- `docs/` : Documentation
